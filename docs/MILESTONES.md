# Delivery milestones

1. Foundation — API, configuration, database, authentication, tests, Docker and CI.
2. Marketplace — organizations, crop catalogue, produce listings and buyer requirements.
3. Agent workflows — orchestrator and specialist agent contracts with grounded tools.
4. Coordination — logistics and storage discovery, quotations and status tracking.
5. Interfaces — dashboard and WhatsApp integration.
6. Trust and transactions — verification, approvals, audit trail and lifecycle.
7. Pilot — validate with real Nigerian farmers, buyers and service providers.
8. Championship — evidence-backed demo, impact metrics, business model and submission.

Milestone completion requires tested, demonstrated workflows rather than documentation alone.
