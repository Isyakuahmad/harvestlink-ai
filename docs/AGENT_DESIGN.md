# Agent design — planned

The orchestrator identifies workflows, delegates typed tasks, validates outputs and returns evidence plus pending approvals. Specialist agents: Farmer, Buyer Matching, Market Intelligence, Logistics, Storage, Trust & Transaction.

Each agent declares purpose, allowed tools, input/output schemas and escalation conditions. Tool outputs are untrusted until validated. Do not fabricate counterparties, prices, inventory, transport or capacity. Record source and timestamp for market observations. Require human approval for commercial offers, purchases, payments and binding commitments.

Evaluate extraction accuracy, unit conversion, match precision, data freshness, tool selection, failure recovery and prevention of unauthorized actions. Track verified matches and completed deliveries in pilots.
