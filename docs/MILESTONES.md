# Delivery milestones

1. Foundation — API, configuration, database, authentication, tests, Docker and CI.
2. Marketplace — organizations, crop catalogue, produce listings and buyer requirements.
3. Agent workflows — orchestrator and specialist agent contracts with grounded tools.
4. Farmer evidence ledger — farm profiles, seasons, activity records, evidence tiers, consented report sharing and access audit. Current MVP implements structured API and JSON reports.
5. Coordination — logistics and storage discovery, quotations and status tracking.
6. Interfaces — dashboard and WhatsApp integration, including farmer-confirmed natural-language/voice entry.
7. Trust and transactions — verification, approvals, audit trail and lifecycle.
8. Pilot — validate with real Nigerian farmers, buyers and service providers.
9. Championship — evidence-backed demo, impact metrics, business model and submission.

Milestone completion requires tested, demonstrated workflows rather than documentation alone.
